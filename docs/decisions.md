# decisions

The short record of why things are the way they are. Add to the bottom; don't rewrite history.

| date    | decision                                                                                                              | why                                                                                                                                 |
| ------- | --------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| 2026-10 | Move from WordPress (VentraIP) to Astro, static                                                                       | Cost (about $250/yr), speed, security, and editing in VS Code instead of a web CMS                                                  |
| 2026-10 | Host on Cloudflare Workers static assets, not Pages or Vercel                                                         | Commercial use on a free tier, previews per branch, DNS already on Cloudflare                                                       |
| 2026-10 | No CMS; Markdown in the repo                                                                                          | All editing happens on one computer, in VS Code                                                                                     |
| 2026-10 | Posts move from `/YYYY/MM/<slug>/` to `/blog/<slug>/`, with a 301 from each old URL                                   | Simpler routing, URLs that don't change with a date edit, evergreen links, one `/blog/` section to filter; only 6 posts to redirect |
| 2026-10 | One fixed list of topics replaces WordPress categories and tags; a topic page needs 2+ posts                          | Several labels per post without thin listing pages; old category URLs 301 to their topic                                            |
| 2026-10 | Keep page URLs (`/projects/`, `/privacy-policy/`, `/terms-of-use/`); let `?p=` shortlinks and `wp-content` URLs lapse | Protect what ranks today without a redirect map for WordPress-only URLs                                                             |
| 2026-10 | Bare domain redirects to www                                                                                          | One canonical host                                                                                                                  |
| 2026-10 | Workers Route at cutover, Custom Domain a week later                                                                  | The route is a one-click rollback while the new site beds in                                                                        |
| 2026-10 | CookieConsent v3, consent reset, Google Consent Mode (advanced); log choices to D1                                    | Keep the current consent model; own the consent record instead of a WordPress plugin                                                |
| 2026-10 | Domain stays registered at VentraIP; mail stays on iCloud                                                             | Cloudflare can't register .au domains; $22.95/yr is fine                                                                            |
| 2026-10 | Brand: path mark, brick and apricot, Martian Mono with Schibsted Grotesk, dark first                                  | Approved in the brand exploration; see brand.md                                                                                     |
| 2026-10 | `design/tokens.json` is the single source for every colour and size                                                   | One place to change the brand; the design system and the code can't drift                                                           |
| 2026-10 | Self-hosted variable woff2 fonts, Latin subset                                                                        | No third-party font requests, smaller files, consent-free                                                                           |
| 2026-10 | Build and develop on Node 24 LTS; Node 22 leaves support in April 2027                                                | Stay on a supported LTS through the launch and beyond; `engines` stays at `>=22.22.0`                                               |
