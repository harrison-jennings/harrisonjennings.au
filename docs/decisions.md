# decisions

The short record of why things are the way they are. Add to the bottom; don't rewrite history.

| date    | decision                                                                                                                                                                         | why                                                                                                                                                             |
| ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2026-10 | Move from WordPress (VentraIP) to Astro, static                                                                                                                                  | Cost (about $250/yr), speed, security, and editing in VS Code instead of a web CMS                                                                              |
| 2026-10 | Host on Cloudflare Workers static assets, not Pages or Vercel                                                                                                                    | Commercial use on a free tier, previews per branch, DNS already on Cloudflare                                                                                   |
| 2026-10 | No CMS; Markdown in the repo                                                                                                                                                     | All editing happens on one computer, in VS Code                                                                                                                 |
| 2026-10 | Posts move from `/YYYY/MM/<slug>/` to `/blog/<slug>/`, with a 301 from each old URL                                                                                              | Simpler routing, URLs that don't change with a date edit, evergreen links, one `/blog/` section to filter; only 6 posts to redirect                             |
| 2026-10 | One fixed list of topics replaces WordPress categories and tags; a topic page needs 2+ posts                                                                                     | Several labels per post without thin listing pages; old category URLs 301 to their topic                                                                        |
| 2026-10 | Keep page URLs (`/projects/`, `/privacy-policy/`, `/terms-of-use/`); let `?p=` shortlinks and `wp-content` URLs lapse                                                            | Protect what ranks today without a redirect map for WordPress-only URLs                                                                                         |
| 2026-10 | Bare domain redirects to www                                                                                                                                                     | One canonical host                                                                                                                                              |
| 2026-10 | Workers Route at cutover, Custom Domain a week later (superseded below)                                                                                                          | The route is a one-click rollback while the new site beds in                                                                                                    |
| 2026-10 | CookieConsent v3, consent reset, Google Consent Mode (advanced); log choices to D1                                                                                               | Keep the current consent model; own the consent record instead of a WordPress plugin                                                                            |
| 2026-10 | Domain stays registered at VentraIP; mail stays on iCloud                                                                                                                        | Cloudflare can't register .au domains; $22.95/yr is fine                                                                                                        |
| 2026-10 | Brand: path mark, brick and apricot, Martian Mono with Schibsted Grotesk, dark first                                                                                             | Approved in the brand exploration; see brand.md                                                                                                                 |
| 2026-10 | `design/tokens.json` is the single source for every colour and size                                                                                                              | One place to change the brand; the design system and the code can't drift                                                                                       |
| 2026-10 | Self-hosted variable woff2 fonts, Latin subset                                                                                                                                   | No third-party font requests, smaller files, consent-free                                                                                                       |
| 2026-10 | Build and develop on Node 24 LTS; Node 22 leaves support in April 2027                                                                                                           | Stay on a supported LTS through the launch and beyond; `engines` stays at `>=22.22.0`                                                                           |
| 2026-10 | Dependabot groups minor and patch updates; each major update gets its own PR                                                                                                     | A breaking major (like TypeScript 7 before Astro supported it) cannot block routine updates; closing its PR skips that version                                  |
| 2026-10 | Dark on every first visit; a sun/moon toggle switches and remembers the theme                                                                                                    | Dark is the primary look, so every first impression is the same; the saved choice is functional, not tracking                                                   |
| 2026-10 | The footer keeps a "© year" line after the legal links                                                                                                                           | Not in the approved mockups, but wanted; later design work keeps it                                                                                             |
| 2026-10 | "book a call" stays on the site: home scrolls to the booking band; other pages open the calendar in a modal                                                                      | A jump link alone would pull blog readers off the post; Cal.com still loads only when asked                                                                     |
| 2026-10 | The compact nav doesn't reopen on hover, only on keyboard focus                                                                                                                  | Reopening moved the links out from under the pointer                                                                                                            |
| 2026-10 | Every post image opens an image viewer (zoom to 400%, drag, step); `{nozoom}` opts out                                                                                           | Posts carry detailed diagrams and screenshots; the large file loads only when the viewer opens                                                                  |
| 2026-10 | Reading time is worked out at build: prose words ÷ 230, rounded up; code doesn't count                                                                                           | No hand-kept numbers to drift; code is read differently from prose                                                                                              |
| 2026-10 | A post's main topic is the first in its `topics` list                                                                                                                            | One rule for the eyebrow and the single tag on cards, with no extra field                                                                                       |
| 2026-10 | "keep reading": most shared topics, newest first on a tie, topped up with the latest; `related:` overrides                                                                       | Relevant by default, with a manual override when the automatic pick is wrong                                                                                    |
| 2026-10 | On highlighted code lines, keywords lift 20% towards text                                                                                                                        | Brick on the brick highlight band was 4.35:1, under AA                                                                                                          |
| 2026-10 | Code blocks always use the dark treatment, on light pages too; inline code follows the page                                                                                      | The light code colours were too close in hue to tell apart, and other hues break the brand                                                                      |
| 2026-10 | RSS is a raw feed at `/rss.xml` (and one per topic page) plus a normal page at `/rss/` that explains it; no XSLT styling                                                         | Chrome removes XSLT, the usual way to style a feed, on 17 November 2026, and Firefox and Safari plan to follow                                                  |
| 2026-10 | Migrated posts keep their WordPress feed guid (`?p=<wpId>`), and `/feed/` 301s to `/rss.xml`                                                                                     | Subscribers carry over without the old posts arriving again as new                                                                                              |
| 2026-10 | Feed items carry the post's description and a link to the full post, not its full text                                                                                           | Figures, video, the image viewer and code copying only work on the site; the full post is one click away; the WordPress feed was already summaries              |
| 2026-10 | Project screenshots stay still: no scroll effect, and never a link                                                                                                               | The expanding screenshot was tried in design and dropped; the name and links are the ways in                                                                    |
| 2026-10 | Share cards are generated at build (Satori and sharp), dark only, one per page; pages without their own share the home card                                                      | Every page gets an on-brand preview with nothing to make by hand; share previews have no light mode                                                             |
| 2026-10 | Satori pinned to 0.33.5, with static font instances made from the site's variable fonts                                                                                          | 0.33.5 predates a burst of daily releases that began in October 2026; Satori can't read variable fonts                                                          |
| 2026-10 | Topics: adobe marketo engage, cloud, web development, analytics. Marketing automation merges into Marketo; marketing technology, api and general redirect to `/blog/`            | Marketing automation held exactly the Marketo posts; marketing technology was on five of six posts; the rest had one post each                                  |
| 2026-10 | Migrated posts keep their WordPress slugs and the dates WordPress showed (UTC)                                                                                                   | The new URLs only drop the date folders, and readers and feed subscribers see the same dates as before                                                          |
| 2026-10 | In migrated posts, pull quotes that repeated the sentence beside them are dropped, and diagrams drawn as quote blocks become plain-text code blocks                              | The design has no pull quote; a monospace block keeps the arrows lined up                                                                                       |
| 2026-10 | Phone menu links show keyboard focus with the hover treatment (brick text and underline), not the focus ring; a tap focuses the menu itself, so nothing shows                    | The ring clashed with the current-page underline and the brand; focus stays visible for keyboard users                                                          |
| 2026-10 | Project screenshots stay 16:9 on phones, not 4:3                                                                                                                                 | The screenshots are wide desktop interfaces; a 4:3 crop cut off what they show (the request builder, the email previews)                                        |
| 2026-10 | CookieConsent v3 keeps the consent; the banner and dialog are our own markup, its interface is never shown                                                                       | The design's banner is a labelled region (not a modal) with `role="switch"` toggles and an "always on" label; CookieConsent's markup is a modal with checkboxes |
| 2026-10 | Consent Mode is set by the site (defaults and a saved choice in `<head>`, updates on each choice), not a Tag Manager template                                                    | The consent logic is tested with the site; a returning visitor's choice applies before Tag Manager loads                                                        |
| 2026-10 | Tag Manager: Live on production builds, Testing on branch previews, nothing locally or in tests                                                                                  | Previews can be checked end to end while sending only to the testing GA4 property                                                                               |
| 2026-10 | The consent log keeps one row per choice, with the IP as an HMAC-SHA256 hash rather than raw                                                                                     | A change adds a row, so the history is kept; the hash can be matched against an IP someone gives but can't be read back                                         |
| 2026-10 | Cookie settings buttons use `data-consent-preferences`, not CookieConsent's `data-cc`                                                                                            | CookieConsent binds `data-cc` to its own interface                                                                                                              |
| 2026-10 | Advanced Consent Mode stays: with nothing accepted, Google gets cookieless pings (no cookies or identifiers)                                                                     | GA4 can model visits from people who decline; the privacy policy already says so                                                                                |
| 2026-10 | Previews log consent to their own D1 database, with no IP key                                                                                                                    | Previews don't inherit production bindings, and test clicks don't belong in the production consent log                                                          |
| 2026-10 | A GitHub Actions workflow comments each PR's preview link                                                                                                                        | Workers Builds skips its comment when a PR opens after the branch's first push                                                                                  |
| 2026-10 | One cookie list (`consent.yaml`) feeds both the cookie preferences and the privacy policy's tables; the advertising category says it sets nothing until an ad tag is switched on | The banner and the policy can't disagree; a placeholder row doesn't belong in a published policy                                                                |
| 2026-10 | Consent records are kept with no fixed deletion date for now (superseded below)                                                                                                  | Harrison's call; the policy says they're kept only as long as needed to demonstrate consent. A fixed period would need a scheduled deletion job                 |
| 2026-10 | Content-Security-Policy written by the build (hashes for the head's inline scripts), sent Report-Only until the reports are clean after cutover                                  | Hashes suit a static site (nonces need a server); Report-Only shows what Tag Manager loads on real visits without breaking analytics while it's fixed           |
| 2026-10 | CSP reports go to `/api/csp-report` and are counted in a `csp_report` table in the consent database, one row per distinct violation                                              | Reviewable after a week (Workers Logs keep three days); counting keeps the table short; no visitor data, no second database to set up                           |
| 2026-10 | Component scripts always ship as files, never inlined into the page                                                                                                              | Keeps the policy to three hashes that only change when the head scripts do, well inside Cloudflare's 2,000-character `_headers` line                            |
| 2026-10 | Tag Manager: no Custom JavaScript variables or Custom HTML tags; built-in tags, gallery or custom templates, and server-side tags instead                                        | They need `'unsafe-eval'` and `'unsafe-inline'`, which would undo most of the CSP; templates run sandboxed and declare what they load                           |
| 2026-10 | SEO aims past parity with WordPress: structured data on every page, sitemap dates, and search titles and descriptions written for real queries                                   | Most WordPress posts were "crawled – currently not indexed"; level with that isn't good enough                                                                  |
| 2026-10 | Sitemap `lastmod` only where there's a real date (posts, the blog, topics, legal pages); none for the rest                                                                       | Search engines ignore `lastmod` once it proves unreliable, so a guessed date costs more than a missing one                                                      |
| 2026-10 | Posts can carry a `searchTitle` and `searchDescription` for search results and share previews; the headline, dek and analytics page name stay as written                         | Search wording leads with the terms people search for; the page keeps Harrison's voice, and reports stay continuous                                             |
| 2026-10 | CI and CD run as two orchestrator workflows calling reusable ones; Cloudflare keeps deploying, and the CD side smoke-tests around its deploys                                    | One run, one tick per change; deploys stay with Workers Builds (recorded earlier), so CD watches them rather than doing them                                    |
| 2026-10 | Lighthouse CI runs `@lhci/cli` through `npx` at a pinned version, not as a dev dependency                                                                                        | Its dependencies carry high-severity advisories with no fix; a throwaway CI runner scanning our own pages makes it a low, accepted risk; Dependabot stays quiet |
| 2026-10 | The hero field reads its colours when the theme changes, not on every frame                                                                                                      | Reading computed styles each frame forced style recalculation; Lighthouse counted it as blocking time (home performance 92, now 99)                             |
| 2026-10 | GitHub Actions may run only GitHub-owned actions and this repository's workflows; required checks are pinned to GitHub Actions as their source                                   | Third-party actions are a common supply-chain route, and every action used is GitHub's; pinning stops another app satisfying a check by name                    |
| 2026-10 | The CD Orchestrator records Cloudflare's preview and production deploys as GitHub deployments (Preview and Production environments)                                              | Workers Builds only posts a check, so the Deployments panel stayed empty; recording them shows what's live where, on the PR and the repository page             |
| 2026-10 | The hero field's motion is scaled by real frame time, at the pace it had at 60 frames a second                                                                                   | It was per frame, so once frames got cheaper a 120 Hz screen ran it twice as fast and the liquid lag went; now it's the same on every screen                    |
| 2026-10 | Licences: code MIT; writing and original graphics CC BY 4.0; testimonials and third-party material excluded; name, logo, brand, photos and legal pages all rights reserved       | Matches the Terms of Use (CC BY since 27 September, and not revocable for copies already taken); reuse of the writing spreads credit and links back             |
| 2026-10 | Bot Fight Mode stays on; its inline JavaScript Detections scripts are left refused by the CSP and their reports dropped                                                          | It protects measure and /api/* (the bot traffic in the sGTM post); the script changes per request, and a nonce would need Worker code on every page             |
| 2026-10 | Cloudflare Web Analytics and Email Address Obfuscation stay on: the beacon is allowed in the CSP and named in the privacy policy                                                 | Web Analytics is cookieless and useful at a glance; the obfuscation decode script loads from the site itself                                                    |
| 2026-10 | The CD smoke test runs against each deployed version's workers.dev preview address with the Access service token (repository secrets), plus light live-domain checks             | Bot Fight Mode challenges GitHub's runners on the real domain and can't be exempted on the free plan; this keeps all CI/CD reporting in GitHub                  |
| 2026-10 | Launched on 20 October, two weeks ahead of the 4 November target                                                                                                                 | All launch steps were ready and rehearsed that day; rollback is instant, and the decommission ends well before the 11 November renewal                          |
| 2026-10 | The API endpoints read bodies through a byte cap, accept only coherent consent records of the current revision, and sit behind one WAF rate limit on `/api/*`                    | `Origin` only stops other sites; anything can post. A WAF rule stops floods before the Worker runs, with no code, and the free plan has one                     |
| 2026-10 | Consent records kept 12 months, CSP reports 90 days, deleted by a daily Cron Trigger on the Worker                                                                               | Australian privacy law expects records destroyed once not needed; 12 months is twice the consent cookie's life, and the policy now states it                    |
| 2026-10 | Phone layouts keep "book a call", "go home" and "save choices" visually first, out of DOM order                                                                                  | Matching both widths would change approved layouts; the controls are adjacent, fully operable, and read sensibly in DOM order (WCAG 2.4.3 is met)               |
| 2026-10 | GitHub Actions pinned to full commit SHAs, with the version in a comment, and SHA pinning required by the repository setting                                                     | Tags can be moved; a SHA can't. Dependabot already updates the Actions weekly and moves the SHA and comment together                                            |
| 2026-10 | The Workers Route stays; no Custom Domain                                                                                                                                        | A swap means deleting the live `www` record first, and resolvers then cache its absence for up to 30 minutes; the route with a proxied CNAME is fully supported |
| 2026-10 | No extra room at the page bottom for the cookie banner; until a choice, it can cover the end of the footer                                                                       | Scrolling past the footer felt wrong; the banner asks for an answer. Focus still stops above it mid-page (WCAG 2.4.11 accepted at the bottom)                   |
| 2026-10 | Front Matter CMS (VS Code extension) as an optional editor over the same Markdown files                                                                                          | A dashboard, forms and snippets without a CMS to host; the schemas and the build stay the gatekeepers                                                           |
| 2026-10 | AI search and assistants may crawl; AI training may not: Cloudflare blocks training crawlers, and robots.txt says so                                                             | Citations from AI answers are discovery, like search; training takes the writing without credit. Some opt-outs exist only in robots.txt                         |
| 2026-10 | Links to other sites, anywhere on the site, open in a new tab, with noopener and a hidden "(opens in a new tab)"; links within the site don't                                    | Readers keep their place in a long post; the hidden note tells screen-reader users before it happens                                                            |
