## how it behaves

- **Five or more quotes:** a row drifting left on an 80-second loop across the full page width. It pauses on hover and focus, and a pause button stops it outright.
- **Fewer than five:** the cards sit still, side by side (a swipe row on phones).
- **Cards** share the tallest card's height, so the names line up. Each is a quote of up to 280 characters, a name and a role.
- **The title** is "what people are saying", never "what clients say".

## props

None. Its quotes come from `src/content/testimonials.yaml`.

## accessibility

- **A pause button** for the moving row (WCAG 2.2.2), as well as pausing on hover and focus.
- **Each quote is read once:** the loop's second set of cards is hidden from screen readers.
- **Reduced motion:** no drift; the row scrolls by hand, and the pause button goes.
