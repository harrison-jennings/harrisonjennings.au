## how it behaves

- **Fills the screen** in `ground`. Its top row sits exactly where the bar was, so the close button replaces the menu button under the thumb.
- **Links** in Martian Mono at 30px (`display-s`), 14px apart; the current page underlined in brick.
- **"book a call"** full width (`size="block"`), and GitHub and LinkedIn as plain 48px icons, lined up with the links.
- **Opening** moves focus into the menu. Escape and the close button close it and return focus to the menu button; so does any link.

## accessibility

- **A real dialog** (`<dialog>`, opened modally), named "Menu", so the page behind it is out of reach while it's open.
- **Focus goes in and comes back:** into the menu on open, back to the menu button on close.
- **48px targets** for the icons, larger than elsewhere, because it's only ever used by touch.
