## accessibility

- **The right element.** A link when it goes somewhere, a button when it does something on the page.
- **One label.** The wipe repeats the words for the animation, but it's hidden from screen readers.
- **Contrast.** `on-accent` on `accent` is <Ratio fg="on-accent" bg="accent" />. Never white text on the dark-theme brick.
- **Focus.** The site's focus ring, and the wipe plays, so keyboard users see the same change as a pointer.
- **Reduced motion.** The wipe becomes an instant colour change.
- **A link to another site** opens in a new tab and says so to screen readers.
