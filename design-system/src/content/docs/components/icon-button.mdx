## accessibility

- **A name for an icon on its own.** `label` is the link's accessible name ("GitHub profile"), with the new-tab note after it.
- **44px to tap,** 48px in the phone menu, whatever the size of the glyph.
- **Opens in a new tab** (`rel="me noopener"`), and says so.
