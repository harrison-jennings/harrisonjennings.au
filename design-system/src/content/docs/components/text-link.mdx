## accessibility

- **Underlined,** so a link never depends on colour alone.
- **Contrast.** `text` on `ground` is <Ratio fg="text" bg="ground" />; the hover colour, `link` on `surface`, is <Ratio fg="link" bg="surface" />.
- **A link to another site** opens in a new tab and says so to screen readers.
- **Focus** shows the site's focus ring as well as the hover colour.
