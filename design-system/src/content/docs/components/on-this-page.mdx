## how it behaves

- **When it shows:** a post with three or more sections (`##`), unless its front matter sets `toc: false`.
- **Desktop:** a column beside the text that stays in view and marks the section being read.
- **Phones:** a closed panel above the text; open it to jump to a section.
- **What it lists:** the h2s, and the h3s indented under them. Footnotes' own heading is left out.
- **The design system** uses the same script for its own "on this page".

## accessibility

- **A labelled navigation landmark,** with the section being read marked `aria-current`.
- **The phone panel is a `<details>`,** so it opens and closes from the keyboard with nothing extra.
