## accessibility

- **A name when it's alone.** With `label` it's an image with that name; without, it's hidden, for when the name is set beside it.
- **A loader says what's loading** in words beside it, as the booking band does.
- **Reduced motion:** it appears drawn, and the dot sits at rest.
