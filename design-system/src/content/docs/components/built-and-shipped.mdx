## how it behaves

- **Desktop:** numbered tabs (01, 02…) with the project names beside the chosen project: a 16:9 screenshot, its description and its links. Panes crossfade over 280ms. The tabs take any number of projects without the section growing.
- **Phones:** one full-width card per project in a swipe row, so long names wrap instead of being cut off.
- **Links,** each only if the project has it: "live at" and its host, "source on github", "read the story". An archived project has no "live at".
- **"all projects"** goes to /projects/.
- **Which projects:** those marked `featured` in `src/content/projects.yaml`, in their `order`.

## props

None. Its projects come from `src/content/projects.yaml`.

## accessibility

- **Real tabs** (`role="tablist"`), with arrow, Home and End keys; only the chosen pane is shown to everyone.
- **Screenshots** have alternative text that says what they show.
- **Reduced motion:** the panes swap without the crossfade.
