## accessibility

- **Says it worked.** "copied" is announced (the label is a polite live region), then the label comes back.
- **`context` finishes the name** for screen readers when the label alone is vague: "copy" + "the cloud feed address".
- **If the clipboard is blocked,** nothing changes, and what it would copy is still on the page to select.
