## how it behaves

- **Shows the current theme:** a moon in dark, a sun in light. Its label says the action ("Switch to light mode" while dark), and changes with every switch.
- **Dark on every first visit,** whatever the device is set to. The choice is saved in `localStorage` (`hj-theme`) and applied by `ThemeHead`'s script before the page paints, so there's no flash.
- **The switch:** the outgoing icon turns a quarter and fades as the other arrives, over 320ms. Instant under reduced motion.
- **In the nav,** after the page links. On phones it stays in the bar beside the menu button.

## props

None. Put `ThemeHead` in the page's `<head>` (the site's layout does) and the toggle anywhere.

## accessibility

- **A real button,** with a label that says what it will do, updated as the theme changes.
- **44px to tap,** like the icon buttons beside it.
- **Both themes are held to the same 4.5:1 for text,** so neither is the "accessible" one.
