## rules

- **Controls are pills.** Every button, the nav bar, icon buttons, tags and the live dot use `radius-pill`.
- **Bigger things get rounder corners.** Code blocks `radius-sm`, screenshots `radius-md`, panels and cards `radius-lg`, full-bleed panels `radius-xl`.
- **A thing inside a rounded thing has a smaller radius than it,** so the gap between them stays even.
