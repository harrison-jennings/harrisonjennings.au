## writing them

`<YouTube id="…" title="what it shows" />`, where the id is the part after `v=` in the video's address. For a still frame, save one beside the post (16:9), import it at the top of the post, and pass it as `poster`. It's a component, so it works in `.mdx` posts only.

## when to use them

<DoDont>
  <DoDontCard verdict="do" say="A title that says what the video shows: it's the player's name for screen readers." />
  <DoDontCard verdict="don't" say="Embed YouTube's own player code. It loads Google's scripts before anyone agrees to them." />
</DoDont>
