## what it holds

<DoDont cols={3}>
  <DoDontCard name="**bold**" say="For the one phrase that matters most. Not for whole sentences." />
  <DoDontCard name="_italic_" say="For titles of things, and asides." />
  <DoDontCard name="`inline code`" say="For anything you'd type: a field, a function, a file name. It wraps rather than run off a phone." />
</DoDont>

Links are written as plain Markdown, `[words](address)`. A link to another site opens in a new tab, with a hidden "(opens in a new tab)" for screen readers; links within the site stay in the same tab.
