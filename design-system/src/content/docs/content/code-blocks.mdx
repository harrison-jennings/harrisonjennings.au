## the three kinds

<DoDont cols={3}>
  <DoDontCard name="```js" say="The language after the fence sets the highlighting and the label. Nothing is guessed: no language is plain text." />
  <DoDontCard name='```js title="…"' say="Adds the file name to the bar, before the language." />

Code is left exactly as written: the formatter doesn't touch code in posts, and long lines scroll rather than wrap. Velocity (`vtl`) is highlighted too, with quotes treated as strings only inside a directive's parentheses, so output text stays plain.
