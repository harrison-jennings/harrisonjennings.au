Static copies of the mark for places that can't read the tokens: favicons, social share images, email signatures, slides.

- `hj-mark-on-dark.svg`: stroke #EFEAE6 (`text`, dark), dot #C85A52 (`accent`, dark). Use on `ground` #121110 or darker.
- `hj-mark-on-light.svg`: stroke #1A1615 (`text`, light), dot #A8443D (`accent`, light). Use on `ground` #F4EFEB or lighter.
- `hj-favicon.svg` (64px), `hj-favicon-32.svg`, `hj-favicon-16.svg`: the mark on a #1C1A19 (`surface`, dark) tile with radius 14 / 7 / 4; stroke 13 / 15 / 17 and dot 8.5 / 9.5 / 10.5 so it stays legible small.
- On a page, prefer the inline mark (`HJ.markSvg`) so it follows the theme.
