Links in running text and link rows: the text colour with a brick underline.

**Markup:** `<a class="hj-link" href="…">read the story</a>`; `.hj-link--quiet` for standalone links that start in the link colour ("all projects").

- Rest: `text`, 1px `accent` underline, 5px offset.
- Hover: text and underline turn `link`; the underline thickens to 2px (150ms).
- Link text says where it goes ("read the story", "source on github"); never "click here".
- `.is-hover` shows the hover state in mockups.
