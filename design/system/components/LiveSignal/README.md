The live dot: marks a deployed project that is up, with its host.

**Markup:** `<span class="hj-live"><span class="hj-live__dot" aria-hidden="true"></span>live at leadlens.harrisonjennings.au</span>`.

- 8px `accent` dot with a 4px `shadow-signal` halo and a ring that pulses outward every 1.8s (still under reduced motion).
- The text is 14px `muted`. Use it only for things that are genuinely live; the words carry the meaning, the dot only reinforces it.
