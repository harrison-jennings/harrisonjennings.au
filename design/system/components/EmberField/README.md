The ember atmosphere: two soft radial clouds, brick and apricot, over the ground colour.

**Markup:** add `.hj-ember` to a large container; its `::before` paints the clouds behind the content. `.hj-ember-bar` shows the linear ember gradient (`ember-from` → `ember-to`) as a swatch.

**Where:** the hero field, social share images and the 404 page. Nowhere else.

- Clouds sit right; put copy on the left half.
- Text, the logo and buttons on ember keep their normal solid colours. No gradient text, gradient buttons or gradient logo.
- Light mode uses richer cloud values automatically (`cloud-brick`, `cloud-apricot`).
